# Uniswap LP ROI Calculator

Simple calculator for **Uniswap V2 style 50/50 pools** (e.g., TOKEN/USDC).  
It estimates:
- Impermanent loss (IL)
- LP value vs. just holding (HODL)
- Total ROI including fees (APR × days/365)

**Assumptions:** 2-asset constant-product pool, 50/50 at entry, no price impact or compounding, fees as a flat APR.

- **Live demo:** https://ralida.github.io/uniswap-roi-calculator
